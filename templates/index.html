Features

How Predictions Are Made

Three models, each with a different learning strategy, combined through composite scoring.

▲

XGBoost

Gradient-boosted decision trees with histogram-based training. 2,000 trees at max_depth=6 with L1/L2 regularisation and early stopping.

■

LightGBM (GPU)

Leaf-wise tree growth accelerated on NVIDIA GPU. Trained with the same 2,000-tree budget and early stopping, converging in ~16 seconds.

◆

Random Forest

Bootstrap-aggregated ensemble of 300 decision trees (max_depth=25) utilising all CPU cores via n_jobs=-1 for parallel training.

☐

Weighted Ensemble

Each model is scored on test-set R², MAE, and MAPE. The composite determines each model's weight in the final prediction. Output includes a price range at ±1.5σ with confidence level.

Using the System

Three steps to get a prediction.

1

Select Location

Choose the state and city from our database of 20 states and 42 cities. The city-specific median price-per-sqft rate is automatically loaded.

2

Enter Property Details

Provide BHK, size, furnishing status, floor, amenities, and other attributes. The API validates every field — types, ranges, and logical consistency (e.g. floor ≤ total floors).

3

View Results

Each model returns a price. The ensemble combines them into a weighted prediction with a confidence-scored range. All responses include per-model breakdowns and latency.

Model Performance

Evaluated on a held-out test set of 49,709 records (70/10/20 train/val/test split).
